Prism Launcher Recommended · updates itself

A ready-made instance that downloads the right mods every time you start the game, so it always matches the server.

  1. Install Prism Launcher and log in with your Minecraft account.
  2. ⬇ Download the instance
    Drag the downloaded file into Prism, or use Add Instance → Import.
  3. Press Launch. The first start downloads the mods; later starts only fetch what changed. The server is already in your multiplayer list.

Set up an existing Prism or MultiMC instance by hand
  1. Create an instance with Minecraft {{minecraft}} and {{loader}}.
  2. Put packwiz-installer-bootstrap.jar in the instance's .minecraft folder.
  3. In Edit → Settings → Custom commands, enable custom commands and set the pre-launch command to:
    "$INST_JAVA" -jar packwiz-installer-bootstrap.jar {{pack_url}}
